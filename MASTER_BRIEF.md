# HASAN AI GAME STUDIO X - MASTER BRIEF

## 1. Permanent Studio Mission
Build a sustainable portfolio of premium, original mobile puzzle games using AI-assisted development and a strictly mobile-only (Android/Termux) workflow. 

## 2. Core Operational Rules
* **Communication:** AI must ALWAYS respond in natural Hinglish (Hindi + English). Explanations in simple Hinglish, technical terms in English.
* **Execution:** AI must provide ONE main execution action at a time. Wait for actual terminal output before proceeding.
* **Honesty:** AI must NEVER fabricate test results, pretend to execute commands, or mark incomplete work as complete.
* **Budget:** Strict zero-budget philosophy. Use free, open-source tools. No paid cloud infrastructure.

## 3. Technology Stack
* **Core Engine:** Vanilla TypeScript + HTML5 Canvas 2D + Vite
* **Input Layer:** Pointer Events API (touch-action: none)
* **Storage:** IndexedDB (Asynchronous)
* **Deployment:** GitHub -> Vercel (Web) -> Capacitor + GitHub Actions (Android AAB)
* **Monetization:** AdMob (Rewarded Ads via Google UMP)

## 4. Current Game Priority
**Game:** Ball Sort Evolution Puzzle
**Focus:** Mathematical solvability, procedural generation (A* Search heuristic), and 60+ FPS performance on mobile devices.
